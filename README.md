# GT 5 Pro 手表应用

## [腕上课表](schedule/)

面向华为 WATCH GT 5 Pro 圆屏的轻量应用，内置一周虚构课程。点击日期两侧的箭头翻页，在课程卡片上向上或向下滑动，查看同一天的其他课程。

在 Windows 上将仓库克隆到不含空格的路径，用 DevEco Studio 打开 `schedule` 目录。打开 [index.hml](schedule/entry/src/main/js/MainAbility/pages/index/index.hml) 并展开 Previewer，即可在 LiteWearable 圆屏上预览。

示例数据位于 [index.js](schedule/entry/src/main/js/MainAbility/pages/index/index.js) 的 `week` 数组中。
